## V1.0 -- Initial Build

**Commit:** `c4c5c50`

Built the full dashboard from scratch. This was the foundation release covering all core features and infrastructure.

### Pages and Routes

- **Team Scorecard** -- aggregated rep performance view with KPI cards
- **Meeting Feed** -- chronological list of all processed meetings
- **Meeting Detail** -- full meeting breakdown with scores, transcript, and actions
- **Companies** -- company-level intelligence aggregation
- **AI Search** -- natural language search over meeting data via RAG
- **System Health** -- monitoring page for pipeline and sync status

### RAG Pipeline

- Gemini embeddings for vector generation
- pgvector for similarity search in Supabase
- Claude Sonnet 4 for streaming AI responses
- End-to-end: user query -> embedding -> vector search -> context assembly -> Claude response

### Scoring Engine

- Stage-specific scoring across 4 meeting types:
  - Discovery
  - Follow-up
  - Onboarding
  - Internal
- Scores generated by n8n pipeline, stored in `scored_meetings`

### Actions

- **Draft Email** -- 3 templates (follow-up, summary, next steps)
- **Re-summarize** -- 4 output formats for different audiences
- **Meeting Prep** -- generate prep brief from prior meeting context

### Auth

- Supabase email/password authentication
- Protected routes with session middleware

### Deployment

- Vercel hosting
- Environment variables managed via Vercel dashboard

## V1.3

**Commits:** `b176563` through `3a37572`

Analytics, rate limiting, RAG performance optimization, and collaborative meeting notes.

### Branding

- **Renamed "AI Search" to "Ask Blarney"** across all routes, components, sidebar, and Cmd+K entries

### Chat Analytics

- **`chat_analytics` Supabase table** -- stores every query, response metadata, and feedback
- **Server-side query logging** -- all AI interactions logged with timestamps, token counts, and latency

### Rate Limiting

- **50 queries/day** per user (daily cap)
- **10 queries/5 minutes** burst limit
- Both thresholds configurable via environment variables
- **Fail-open design** -- if rate limit check errors, the query proceeds rather than blocking the user

### User Feedback

- **Thumbs up/down** on AI responses -- stored in `chat_analytics` table
- Feedback linked to specific query-response pairs for quality analysis

### Clear Chat

- **Confirmation dialog** before clearing conversation
- **Soft delete** -- conversation removed from UI but analytics data permanently retained in Supabase

### Turn Management

- **Removed hard 10-turn cap** from V1.2
- **Replaced with soft nudge at 15+ turns** -- suggests starting a new conversation but doesn't block

### RAG Performance

- **Parallel API calls** -- embedding lookup and score data fetch run concurrently (~500ms faster)
- **Dynamic chunk count** -- 8, 12, or 15 chunks based on query complexity
- **Increased max tokens** to 4096 for longer, more detailed responses
- **16-turn history** -- conversation context window expanded for better follow-up handling

### Source Citation Fix

- **Meeting IDs now included in score context** -- Claude receives real UUIDs so source citations link to actual meetings instead of generating hallucinated IDs

### Meeting Notes

- **Section-level notes** -- add notes to specific sections of a meeting (coaching, actions, decisions, etc.)
- **Persistent storage** in Supabase -- notes survive page refreshes and browser changes
- **Multi-user support** -- each user's notes are stored independently
